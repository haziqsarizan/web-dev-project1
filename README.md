# Web Dev Project 1

A web-based inventory system built with PHP, MySQL and Bootstrap for TTTM2113 Web Development.

## Status
Work in progress. Currently on **PT1**.

## Planned features
- Dashboard
- Products, Customers and Staff pages
- Orders and invoices

## Built with
- PHP
- Bootstrap 5 and Bootstrap Icons
- Laragon (local server)

## How to run
1. Install Laragon
2. Put this folder in `C:\laragon\www`
3. Start Laragon and open `http://localhost/web-dev-project1`
